## Colour scheme

All figures use a consistent colour scheme throughout.

**Aalborg West (AW)** samples are represented in a sequential blue palette 
(ColorBrewer "Blues"), where darker shades indicate higher sludge concentrations:

| Sample     | Hex       | Colour                                                        |

| AW 8 g/L   | `#4393C3` | ![](https://via.placeholder.com/20/4393C3/4393C3.png)        |
| AW 10 g/L  | `#2171B5` | ![](https://via.placeholder.com/20/2171B5/2171B5.png)        |
| AW 14 g/L  | `#1561A9` | ![](https://via.placeholder.com/20/1561A9/1561A9.png)        |

| AW 22 g/L  | `#08306B` | ![](https://via.placeholder.com/20/08306B/08306B.png)        |
