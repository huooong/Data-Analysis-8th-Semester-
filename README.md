All data analysis is done in R.

## Colour scheme

All figures use a consistent colour scheme throughout.

**Aalborg West (AW)** samples are represented in a sequential blue palette 
(ColorBrewer "Blues"), where darker shades indicate higher sludge concentrations:

| Sample     | Hex       | 
|------------|-----------|
| AW 5 g/L   | `#6BAED6` |
| AW 8 g/L   | `#4393C3` |
| AW 10 g/L  | `#2171B5` | 
| AW 14 g/L  | `#1561A9` |
| AW 18 g/L  | `#08519C` | 
| AW 22 g/L  | `#08306B` | 

**Køng** reactors (1–5) are each assigned a distinct colour to allow clear 
visual separation across figures:

| Sample  | Hex       |
|---------|-----------|
| Køng 1  | `#E69F00` | 
| Køng 2  | `#009E73` | 
| Køng 3  | `#CC79A7` | 
| Køng 4  | `#D55E00` | 
| Køng 5  | `#000000` | 

Within each figure, **extraction method** (Alkaline vs CER) is distinguished 
by faceting into separate panels rather than by colour.
